SHRI VETRIVEL DEVELOPERS — WEBSITE

Files:
- index.html: website content
- style.css: responsive styling
- script.js: mobile navigation, current year and WhatsApp enquiry form

Preview:
Open index.html in a modern browser.

Publish free using GitHub Pages:
1. Create/open a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the website.

Before publishing:
- Replace the illustrative concept graphics in Projects with genuine project photos when available.
- Confirm phone numbers, services, social links and company details.
- Add the official logo file if you want the text-based SV mark replaced.
- The enquiry form opens WhatsApp and does not save enquiries to a database.
- If you own a domain, configure it under GitHub Pages after publishing.
